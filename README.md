# SnowRunner-Tow-hitch-for-large-and-scout-trailers-for-the-TUZ-420.
This mod expands the default capabilities of the TUZ 420 "Tatarin" APC, transforming it into a versatile scout and rescue vehicle without breaking game balance or immersion,adds a hitch point for trailers, there is no visual tow hitch display!
